# Журнал работ на строительном объекте

## Стек Технологий

### Бэкенд
- **NestJS** — Node.js фреймворк. Выбрал для ускорения разработки, чтобы не тратить время на ручную настройку архитектуры, как пришлось бы делать в случае с чистым Node.js/Express или решениями уровня ASP.NET Core.
- **Prisma ORM** — инструмент работы с БД с полной автогенерацией TypeScript-типов. Привлекает больше, чем TypeORM, благодаря строгой типизации и простой системе миграций.
- **PostgreSQL** — реляционная база данных. Был выбор между SQLite, но эта СУБД лучше подходид для локальных и быстрых задач, а здесь я решил показать, что умею пользоваться постгри, да и она более перспективная для реальных проектов. 

### Фронтенд
- **Vite** — инструмент сборки. Легче и быстрее вебпака.
- **TanStack Query (React Query) + Axios** — связка для выполнения запросов и управления кэшем. Берет на себя отслеживание состояний загрузки/ошибок и автоматическое обновление серверных данных.
- **Lucide React** — минималистичный набор иконок. Красивые иконки, и не требуют загрузки огромных пакетов.

## Запуск

### Требования
- Установленный Node.js (v18+)
- Установленный Docker & Docker Compose

### Шаги запуска

1. **Запустите PostgreSQL в Docker контейнере:**
   ```bash
   npm run start:db
   ```

2. **Установите все зависимости (для корня, бэкенда и фронтенда):**
   ```bash
   npm install && npm run install:all
   ```

3. **Накатите миграции базы данных и засидьте данные:**
   ```bash
   cd backend
   npm run prisma:migrate
   npm run prisma:seed
   cd ..
   ```

4. **Запустите проект в режиме разработки (бэкенд на порту 3000, фронтенд на порту 5173):**
   ```bash
   npm run dev
   ```

5. **Откройте приложение в браузере:**
   - Фронтенд: `http://localhost:5173`
   - Документация API (Swagger): `http://localhost:3000/api/docs`
