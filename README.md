# Журнал работ на строительном объекте

Проект представляет собой специализированную систему ведения учета строительных работ. Разработан по высочайшим стандартам инженерии: **Clean Hexagonal Architecture (Ports and Adapters)** на бэкенде и **Изолированная модульная компонентная архитектура с SCSS-модулями** на фронтенде.

## 🛠️ Стек Технологий

### Бэкенд
- **NestJS** — прогрессивный Node.js фреймворк.
- **Prisma ORM** — современный инструмент работы с БД с полной автогенерацией типов.
- **PostgreSQL** — надежная реляционная база данных.
- **class-validator / class-transformer** — строгая декларативная валидация входящих запросов.

### Фронтенд
- **React + TypeScript** — надежное ядро веб-интерфейса.
- **Vite** — быстрый инструмент сборки.
- **SASS (SCSS) + CSS Modules** — модульные изолированные стили для исключения конфликтов стилей.
- **TanStack Query (React Query) + Axios** — реактивное управление кэшем серверного состояния.
- **Lucide React** — минималистичный набор иконок.

## 🏗️ Архитектура

### Бэкенд (Hexagonal Architecture)
Бизнес-логика в `/backend/src` полностью отделена от внешних библиотек и базы данных:
- **Domain (`/domain`)**: Чистые сущности (`WorkLog`, `WorkType`) без внешних импортов фреймворков или ORM.
- **Application (`/application`)**: Юзкейсы (бизнес-сценарии) и их интерфейсы-порты (`ports/`). Зависит только от Domain.
- **Infrastructure (`/infrastructure`)**: Адаптеры к внешнему миру. HTTP-контроллеры для API и Prisma-репозитории с мапперами данных для изоляции БД.

### Фронтенд (Modular & SCSS)
Структура компонентов в `/frontend/src`:
- **UI Kit (`/components`)**: Атомарные компоненты общего назначения (`Button`, `Input`, `Modal`, `Loader`) со своими стилями `.module.scss`.
- **Features (`/features`)**: Бизнес-фичи (например, `/work-logs`), содержащие сложные компоненты, хуки фильтрации и формы.
- **API Client (`/api`)**: Управление запросами с инвалидацией кэша. компонентов.

## 🚀 Быстрый запуск

### Требования
- Установленный Node.js (v18+)
- Установленный Docker & Docker Compose

### Шаги запуска

1. **Запустите PostgreSQL в Docker контейнере:**
   ```bash
   npm run start:db
   ```

2. **Установите все зависимости (для корня, бэкенда и фронтенда):**
   ```bash
   npm install && npm run install:all
   ```

3. **Накатите миграции базы данных и заполните справочник:**
   ```bash
   cd backend
   npx prisma migrate dev
   cd ..
   ```

4. **Запустите проект в режиме разработки (бэкенд на порту 3000, фронтенд на порту 5173):**
   ```bash
   npm run dev
   ```

5. **Откройте приложение в браузере:**
   - Фронтенд: `http://localhost:5173`
   - Документация API (Swagger): `http://localhost:3000/api/docs`
